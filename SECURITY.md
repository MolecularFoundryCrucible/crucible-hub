# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's [private vulnerability reporting](https://github.com/MolecularFoundryCrucible/crucible-hub/security/advisories/new) for this repository. Do not open a public issue, pull request, or discussion for a suspected vulnerability.

Include what you found, how to reproduce it, and the impact you expect. We will acknowledge the report, keep you informed while we investigate, and credit you in the release notes if you would like.

## Scope

This policy covers the Crucible Hub web application in this repository. Issues in the Crucible API or other Crucible services should be reported to the maintainers of those repositories; if you are unsure where an issue belongs, report it here and we will route it.

## Supported versions

Only the latest release, deployed from the newest `vX.Y.Z` tag, receives security fixes.
