## Current validation baseline

At commit `8b99faf`, `npm run validate:static` passes 418 unit tests across 56 files plus formatting, lint, strict types, OpenAPI drift, server-boundary protection, token policy, documentation links, and secret scanning. `npm run test:browser` passes 42 tests across six focused files in about 18 seconds, `npm run test:production` builds the application and passes six runtime checks, and `npm run audit` reports no high or critical advisories. The test tree contains no committed screenshots and is approximately 88 KB. CI runs two parallel jobs: static and unit validation, and browser plus production-runtime validation. `npm run validate` remains the complete local gate and adds the production build to `validate:static`. This register summarizes existing evidence and does not imply that every check was rerun for each documentation or UI-only iteration.

All evidence above is fixture or controlled-test evidence unless explicitly marked otherwise. It does not authorize live API access, deployment, release, or production mutation exposure.
