## Current validation baseline

Run `npm run validate` for formatting, lint, strict types, unit tests, OpenAPI drift, server-boundary protection, token policy, documentation links, secret scanning, and production build. Run `npm run test:browser`, `npm run test:production`, and `npm run audit` when their package gate requires them. This register summarizes existing evidence and does not imply that every check was rerun for each documentation or UI-only iteration.

All evidence above is fixture or controlled-test evidence unless explicitly marked otherwise. It does not authorize live API access, deployment, release, or production mutation exposure.
