## Acceptance constraints

- Preserve API authorization as the sole authority and return public-safe, permission-filtered representations where appropriate.
- Publish deterministic OpenAPI artifacts and compatibility evidence before Hub consumes new behavior.
- Define pagination, ordering, nullability, error, and concurrency semantics where they affect Hub state or recovery.
- Do not require a standing platform-administrator credential for normal Hub use.
